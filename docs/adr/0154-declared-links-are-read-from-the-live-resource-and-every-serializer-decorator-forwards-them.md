# Declared links are read from the live resource and every serializer decorator forwards them

The OpenAPI metadata reads a type's declared links (core ADR 0178) from the resource's `allLinks()` when it builds the document, the way it reads fields and filters, so their closures never pass through the compiled container. At runtime the pivot serializers wrap the resource, so each implements core's `RendersDeclaredLinksInterface` and forwards to what it wraps. Without that, a pivot related member or a resource with pivot linkage would silently lose links the document promises. A serializer that replaces a resource through `#[AsJsonApiResource(serializer:)]` has to implement the interface itself, since the metadata still describes the resource's declarations; the bundle doesn't detect one that skips them.
