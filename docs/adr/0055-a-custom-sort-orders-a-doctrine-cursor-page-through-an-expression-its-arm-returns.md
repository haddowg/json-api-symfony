# A custom sort orders a Doctrine cursor page through an expression its arm returns

A cursor page needs each level's `ORDER BY` with nulls as the largest value and a keyset `WHERE` repeating that level as an equality prefix under every later one, and both have to match the in-memory witness exactly. So a custom sort's arm opts in through `DoctrineKeysetSortArmInterface` by returning one DQL expression and the DBAL type its boundary binds with, and `DoctrineKeyset` builds the null ordering, the four after-cases and the prefix from it as it does for a column. We rejected letting the arm write its own order and comparison, since every arm would then reimplement the null handling and could drift from the witness. The cost is that the expression has to fit DQL's `IS NULL` and `ORDER BY` grammar: a path, a function call or `COALESCE`/`NULLIF`, so an arm wanting arithmetic wraps it in a registered function.
