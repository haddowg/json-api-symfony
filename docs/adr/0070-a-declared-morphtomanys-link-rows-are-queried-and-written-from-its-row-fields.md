# A declared MorphToMany's link rows are queried and written from its row fields

A `MorphToMany` declared with `identifiedByRows()` names its `through()` entity and the row fields holding the owner, stored type and id, so the Doctrine layer pages its rows in one query on that entity and maps each row through core's query, and narrows a guarded member type in the same query to the storage keys its provider admits, found through one key-only read for every parent in a batch and core's `LinkRowQuery::narrowed()`, rather than rebuilding pairs by running a closure over a copy of the parent or falling back to memory whenever a scope hides rows. Core plans its writes, so persisters apply the `LinkRowWritePlan` pass by pass through `WritesLinkRowsInterface`, Doctrine flushing after each pass inside the write's transaction, and one write path holds for every provider with `InMemoryLinkRows` as the witness. A relation read through an `identifiedBy()` closure exposes no fields to query, so it is served in memory on every provider and warm-up logs core's notice saying so.
