# A pivot prefix points a relationship filter at the pivot row

A pivot relation's members can need filtering by what hangs off the row that links them to this parent, such as definitions a template uses whose row has no targets, which no filter on the member can answer once a member is shared. We reuse the `pivot.` prefix pivot column filters already use, on the relationship of `WhereHas`, `WhereDoesntHave` and `WhereHasMatching` and on the path of `WhereThrough` and `WhereThroughIn`, so the declaration, the routing to the pivot join and the endpoints that document and accept the filter are the ones pivot filters already have, and core needs no new API or document shape. A path that ends on one of the row's associations compares the id of the entity it reaches, since the row's entity is not a resource whose id core could resolve.
