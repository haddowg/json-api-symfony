# A self-referencing pivot's parent side is the collection the relation is stored as

An association entity with two `ManyToOne`s to the parent class, as one linking a type to itself has, gave both sides the first association found, so a relation read its parent as its own member. The relation already names a property of the parent through `storedAs()`, and the parent's `OneToMany` of the association entity's rows is mapped by exactly the side that points back to it, so that mapping picks the parent side and the remaining association to the far type is the related side. When the relation names no such collection, or the entity holds several candidates for the related side, the resolution throws at warm-up rather than guess, because a wrong guess silently swaps the members of both directions.
