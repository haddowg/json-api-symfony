# A union is stored in core's stored form where its column can't hold a date-time

Core hydrates a top-level `Union` date member to a `\DateTimeImmutable`, but a union's natural Doctrine column is `json`, which encodes that object as `{"date": …, "timezone": …}`, a value no member reads back. Just before the persister writes, the handler asks a `StoresDateTimesInterface` persister whether each union's column holds date-times, and where it doesn't it stores core's `Union::toStoredForm()` of the hydrated value, the member's wire form. Union pivot fields and link-row values are stored the same way from their cast value. We chose this over a bundle DBAL type because a plain `json` column then works with no extra mapping, and a read renders the stored form exactly as it renders the hydrated value. A persister that holds objects, such as the in-memory one, keeps the hydrated value, so the stored PHP type of a union date depends on the store.
